## 3. Resolving the 197 vs 250 discrepancy

- The Mendeley v3 description says Version 2 uploaded **197 raw images**.
- The paper (arXiv:2603.25229) says “around 250 raw images were collected before filtering” and
  “resulting in 250 high-quality images”, then zoom/rotation augmentation to 1,612.
- The files on disk contain **exactly 197 raw images**.

Conclusion: **197 is the number of released raw images**. The paper’s ~250 refers to images
collected/filtered during dataset construction; ~53 source images were not released. Their
identity, labels and derivatives cannot be recovered from the public release. The abstract’s
“250 distinct” must be reported as an author claim, not as a verifiable property of the release.

## 4. v1 and v2 are independent augmentation sets

- Zero byte-identical files between v1 and v2 (MD5).
- Same per-class counts but different filenames (v1 4-digit random-looking suffixes, v2 6-digit).
- DINOv2 nearest-neighbour similarity between v1 and v2 is high but only ~13.5% of pairs are
  mutual nearest neighbours, so v2 is **not** a resized copy of v1. It is a second augmentation
  pass over the same source pool.

Therefore **both versions must be merged into the same source groups**; the release effectively
ships **3,224 augmented images**, not 1,612.

## 5. Naming and duplicate audit

- **Exact duplicates (SHA-256): 0** within or across versions.
- **Perceptual near-duplicates (pHash Hamming ≤ 6, within version):** 451 groups / 1,251 files.
  These are expected augmented derivatives, not accidental copies.
- `Images_v1` has **90 filename collisions / 184 files** across class folders with *different*
  content. Never key on filename; always key on the full path.
- `Images_v2` filenames are unique (1,612/1,612).

## 6. Source-group reconstruction (provisional)

No filename encodes the parent image and the raw folder has no labels, so groups were
reconstructed empirically:

1. **Raw super-groups**: complete-linkage clustering of the 197 raw images on DINOv2 cosine
   distance ≤ 0.15 (similarity ≥ 0.85). → **135 super-groups**, max 4 raw images/group.
   This merges near-identical raw photos (e.g. consecutive indices 132/133) conservatively.
2. **Augmented → raw matching**: DINOv2 shortlist (top 10) + SIFT/RANSAC verification
   (rotation/zoom invariant, matching the paper’s stated augmentation).
   - **Tier A (SIFT-confirmed): 1,507 / 3,224 (46.7%)**, agreement with independent
     dihedral-transform anchors **97.5%**.
   - **Tier B (embedding fallback): 1,717 / 3,224 (53.3%)**, anchor agreement **91.0%**.
3. **Group class agreement** between image label and inferred group class: **98.9%**
   (18 augmented images remain `unknown`). Separately, **61 of the 197 raw images** have no
   labelled descendant in the release and therefore no recoverable class.

## 7. Critical limitations (read before using the group map)

- **Group reconstruction is not exact.** The paper implies ~250 distinct sources, but only 197
  raw images were released and filename metadata is absent. The reconstruction yields **100
  augmented-populated groups**, i.e. substantially **over-merged** relative to the claimed 250.
- Over-merging is *conservative* for leakage control: derivatives of one source are unlikely to
  be split across folds, but statistical power and class balance per fold are reduced. The map
  must **not** be described as a true patient- or source-level ground truth.
- Tier B assignments concentrate in a few “attractor” groups with up to 175 images; they are
  **not** suitable for headline evaluation.
- Per-raw class inference is unreliable (tier-A votes cover 118/197 raws and are class-skewed),
  because ~53 sources are unreleased and their derivatives fall back to the nearest released raw.
- **61/197 raw images have no recoverable class** (no labelled derivative in the release). Only
  **136 raw images** can be used as labelled evaluation samples. Per-class raw groups are highly
  imbalanced: Eczema 42, Tinea Ringworm 20, Vitiligo 10, Dermatitis 9, Scabies 9.

## 8. Recommended use in the protocol

1. **Primary evaluation set = labelled raw images only** (`version == raw` and a recoverable
   class, 136 images), grouped by `group_id`. Raw labels are inferred from their descendants, not
   author-provided; the 61 unlabelled raw images are excluded and reported as a limitation.
2. **Primary training pool = raw images + tier-A derivatives** (`primary_usable == true`,
   1,704 images). This guarantees every training image has a SIFT-confirmed source.
3. Report **tier-B results only as a secondary sensitivity analysis**, with the 53 unreleased
   sources stated as a limitation.
4. Request the augmentation manifest / original source IDs from the authors (manual action).
   Until received, do not claim exact source counts in the abstract.
